# 差异说明：供应商子账户（上号器本地）

日期：2026-11-10。对照 DESIGN v2.2 §7 / §9.3。  
状态：设计稿。实现先出 docs，本文件不改应用代码。

**已拍板（总监，改口后）**：在**上号器本地**给供应商开子账户，**不是**去 JWT 上游站建号。码农对上游 `role=5` 的核对（无用户接口、`/api/user/` 403）作为附录保留，不作为本期实现路径。

---

## 1. 角色与权限

| 能力 | 父供应商 | 子账户 | Admin |
| --- | --- | --- | --- |
| 创建 / 停用 / 重置子账户密码 | ✅ 仅自己名下 | ❌ 不能再建下级 | ✅ 可看全部，可代管 |
| 上 key / 换密钥 | ✅ `owned=true` | ✅ 同左（与父同等渠道能力） | 按原规则 |
| 渠道列表 | 名下全部（含导入只读） | **同父范围**（v1 **不做分配**） | 全部 |
| 账单 / 对账 | 原规则 | **只读**，范围同父 | 原规则 |
| 网关（设置 › 网关） | 按现规则 | ❌ 不渲染入口，API 拒绝 | 原规则 |
| 看其他供应商 | ❌ | ❌ | ✅ |

子账户登录后角色仍是供应商视角（导航无「用户管理」完整 Admin 页），仅少「子账户」管理入口、少网关管理。

服务端强制：`parent_user_id = 父供应商`；所有列表 / 账单 / 写操作不能越权到其他供应商。子账户创建的 `owned=true` 渠道仍归属**父供应商名下**（父与子都看得见、都能管）。

---

## 2. 入口（父供应商）

导航：在「设置」旁（或设置内第一项）增加 **「子账户」**（仅父供应商可见；子账户、未登录不显示）。不要复用 Admin「用户管理」整页。

列表页：

- 表：用户名、状态（启用 / 已停用）、最后登录、操作（停用或启用、重置密码）。
- 黑 CTA「创建子账户」。
- 空态：「还没有子账户，点击「创建子账户」添加」。

创建弹窗 / 小抽屉（440px）：

- 用户名 *、密码 *（`type=password` + 显示；规则与现有开户一致）。
- 灰字说明：「子账户与你共用渠道与账单范围，可以上 key；不能管理网关，也不能再创建下级。」
- 底栏：取消 · 黑「创建」。成功 toast「已创建子账户 {用户名}」。
- 不设角色选择、不设网关权限、不设渠道分配（v1）。

重置密码：二次确认弹窗，新密码一次填写；成功不回显密码到列表。

停用：行内确认「停用后该账号无法登录，已上的 key 仍归你名下」。已停用行 55% 透明，操作改「启用」。

---

## 3. 子账户登录后

- 渠道 / 账单 / 对账：同父供应商数据范围；上 key 规则同 JWT 网关（添加、owned 可改、导入只读、无测试/删除/启停）。
- **无**「子账户」菜单、**无**网关添加/编辑；设置里只留「我的账号」（改自己的密码）。
- 页头或网关条不出现令牌/Access Token 文案（沿用 2026-11-08 账密会话口径）。

---

## 4. Admin

Admin「用户管理」供应商行可展开或进入「子账户 n」；可代为创建 / 停用 / 重置，规则同父供应商，不可把子账户改挂到别的供应商（v1 不支持转移）。

## 6. 非目标

- 不调用上游 `/api/user/`，不在 JWT 站建号。
- v1 不做渠道分配、不做多级子账户、不做子账户独立账单拆分。
- 不在群里或文档写账密明文。

## 附录 · 上游核对（码农，不采用）

本附录只说明上游走不通，**不作为本期实现路径**。不含主机、账号或口令。

现网供应商 `role=5`：

- `GET /api/supplier/v1/profile` 只返回 `supplier_label` 与渠道 kinds/actions，没有用户 / 子账户能力。
- `/api/supplier/v1/users` 及同类供应商用户路径为 404。
- `GET/POST /api/user/`、`POST /api/user/manage` 返回 `403 AUTH_INSUFFICIENT_PRIVILEGE`。
- SPA `/users/` 要求 `role >= ADMIN(10)`。角色枚举：GUEST=0，USER=1，SUPPLIER=5，ADMIN=10，SUPER_ADMIN=100。上游 SPA 没有「子账户」页面或文案。
- 公开注册已开启，但只能建成普通 USER（role=1），不是供应商子账户。

故上游子账户路径走不通，本期只做上号器本地。
