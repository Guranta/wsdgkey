## 必过（SUB-01–10）

- [ ] **SUB-01** 父供应商可「创建子账户」（用户名+密码）；成功 toast；列表出现；空态「还没有子账户，点击「创建子账户」添加」。
- [ ] **SUB-02** 子账户登录后**无**「子账户」入口，不能再建下级；设置只留「我的账号」（可改自己的密码）。
- [ ] **SUB-03** 子账户**无**网关添加/编辑/停用入口；直接打网关写接口被拒绝。
- [ ] **SUB-04** 子账户不能看见其他供应商的网关/渠道/账单。
- [ ] **SUB-05** 渠道范围同父（含导入只读行）；可对 `owned=true` 上 key / 换密钥；导入行无「修改」。
- [ ] **SUB-06** 子账户创建的 `owned=true` 渠道归父供应商名下，父与子都看得见、都能管。
- [ ] **SUB-07** 账单/对账只读，范围同父。
- [ ] **SUB-08** 父供应商可停用（无法登录，已上 key 仍归父名下）、再启用、重置密码（成功不回显到列表）。
- [ ] **SUB-09** Admin 可看全部子账户并代为创建/停用/重置；v1 **不能**把子账户改挂到别的供应商。
- [ ] **SUB-10** 子账户界面无 Access Token /「令牌失效」类文案（沿用 11-08 账密会话口径）。

## 非目标（本轮不测，不作为失败）

- MFA
- 删除子账户
- 数量上限
- 渠道分配
- 上游 JWT 站建号

## 另案

网关卡片「缺少令牌」、设置页「系统访问令牌」是既有 JWT 设置文案的单独修复，**不是本功能**。不计入 SUB-01–10，也不用本验收代替那条修复。SUB-10 只约束子账户界面：无 Access Token /「令牌失效」类文案，沿用 2026-11-08 账密会话口径。
