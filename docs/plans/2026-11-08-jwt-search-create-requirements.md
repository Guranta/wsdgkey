## 1. 老板拍板（原文意图）

1. **全面适配 JWT 站点**（`newapi_supplier`）。
2. **至少能上 key**：供应商网关放开「添加渠道」；能创建并写入密钥；`owned=true` 可改/换 key。
3. **渠道关键词搜索**：列表必须有显眼搜索（框 + 按钮/回车）；约 900+ 导入行必须能按名称/ID 搜到。
4. **鉴权不要令牌**：供应商 JWT **用账号密码**拿会话；access 仅短期票；过期 refresh，失败则密码重登。界面**禁止**「令牌失效请重填 Access Token」。

实现顺序（总监已定）：**搜索 → 创建（原 G8）+ owned 编辑/换 key**；鉴权文案一并改。

| ID | 要求 | 完成标准 |
