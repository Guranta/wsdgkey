## 怎么打开原型

1. 用浏览器（Chrome / Edge / Safari / Firefox）**直接打开** `wireframes.html` 即可，不需要服务器，不需要联网。
2. 右上角有两个切换：
   - **角色**：「供应商 | 管理员」。管理员专属内容（用户管理、创建人列、按供应商占比、网关 / 限流 / 对账容差设置、重新绑定等）会随角色显示或隐藏。
   - **语言**：「中 | EN」。默认语言规则：手动选过的优先；否则浏览器语言是 `en*` 就显示英文，其他一律中文。选择会存到 cookie 和 localStorage 的 `shq-lang`。
3. 页面顶部有灰色「线框演示」条，可以一键打开抽屉、确认弹窗、批量结果、加载态、空态等。
4. 可以用 **hash 路由**直接打开某个页面或状态（格式 `#角色/页面/状态`）：

| hash | 打开的内容 |
|------|-----------|
| （无 hash） | 登录页（bot 脸动画；用户名填 `wrong` 或密码填 `123` 可演示登录失败） |
| `#admin/channels` · `#supplier/channels` | 渠道管理 |
| `#admin/channels/drawer` | 添加渠道抽屉 |
| `#admin/channels/confirm` | 启用 / 禁用确认弹窗 |
| `#admin/channels/batch` | 批量启用结果弹窗 |
| `#admin/channels/test` | 行内测试结果与冷却 |
| `#admin/billing` | 账单（已发布） |
| `#admin/billing/pending` · `/loading` · `/empty` | 账单：汇总中 / 加载中 / 空 |
| `#admin/recon` | 对账 · 每日自动核对 |
| `#admin/recon/supplier` · `#supplier/recon/supplier` | 对账 · 供应商对账 |
| `#admin/users` | 用户管理（供应商访问会提示无权限） |
| `#admin/settings` | 设置 |
| `#admin/settings/dirty` | 设置：有未保存改动（底部保存栏） |

## 版本与变更摘要（v2.1）

完整内容见 `DESIGN.md` §0。

- **页面**：删除 模型 / 对话 / 导出。导航为 5 项：上 key（渠道）、账单、对账、用户管理（仅管理员）、设置。
- **渠道管理**：KPI 小环卡、多 ID 搜索 chips、状态 Tabs、三列消耗（今日之前 / 今日 / 累计）、运行中 / 手动禁用 / 自动禁用 / 网关上已删除 状态、行内自动禁用开关、行内测试（10 分钟冷却，保存或启用后自动测 1 次）、批量启用 / 禁用（**无批量删除、无批量测试**）、服务端分页 20 条 / 页。
- **添加 / 编辑渠道抽屉**：字段、顺序、分组、类型列表与 New API 原表单完全一致（4 个 Tab、52 种类型）；密钥格式只警告不拦截；编辑时只读显示 New API 渠道 ID、创建人、绑定历史。
- **账单**：00:00 开始拉取 → 拉完即发布、最晚 06:00 → 未同步不阻塞、稍后自动补入；donut 看板；测试消耗单列且不计入供应商；未同步不计为 0；两日合计、新建、已重新绑定等标记；只统计通过上号器添加的渠道。
- **对账**（新页）：每日自动核对（只按渠道核对 `/api/log/stat`）、「网关上找不到」清单与重新绑定（仅管理员）、自检异常；供应商对账（月 / 周、2% 自动通过、CSV、备注线程、确认 / 异议、锁定账期 + 追加调整）。
- **设置**：网关管理、拉取限流、对账容差、只读账单时间、底部保存栏。
- **主题与语言**：只保留浅色；中 / EN 双语。
- **品牌**：品牌名「万事大吉」；新 logo 与 favicon；登录页 96px bot 脸动画；移除所有参考品牌字样。
