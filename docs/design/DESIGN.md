## 1. 设计原则

| 做 | 不做 |
|----|------|
| 左栏 roster/导航 + 主区大留白 | Semi 窄侧栏（180px）企业控制台 |
| 黑色 stadium/pill 主 CTA，白字 | `#0064FA` 蓝主色 |
| 彩色角色 avatar blob（点缀） | 整页彩虹 / 登录页 pastel 径向光斑 |
| 卡片低密度，圆角 12–16px | 高密度仪表盘表格墙（表格允许，但疏行距、白卡承载） |
| 系统无衬线，粗标题 + 灰次文 | Lato + 企业蓝链接堆 |
| 数据以 donut 为视觉中心 | 企业蓝单色柱状图 |

主铬保持 **白 / `#F8F8F8` + 黑操作**；颜色只活在 **头像、状态点、图表系列、空态插画、点缀 pill**。

## 8. 组件规则

### 8.1 按钮

- **Primary（CTA）**：bg `#0A0A0A`、hover `#2A2A2A`，字白，**h 44px**，`border-radius: 999px`；表格工具栏内可用 sm（h 34px）
- **Secondary**：bg `#F3F3F3`，字 `#0A0A0A`，stadium
- **Ghost**：文字钮，h 28–32px，hover `#F3F3F3`；表格「操作」列默认
- **Danger**：软红底 + 红字；删除 / 禁用确认
- Disabled：opacity 0.45

### 8.2 输入框 / Select / Textarea

- 填充 `#F3F3F3`，无边，radius 12px，h 44px（筛选栏 36px）
- Focus：白底 + 1.5px `--text` 边 + 黑半透明 ring
- Error（仅必填缺失）：1.5px `--danger` 边 + 下方 12px 红字
- Warning（格式可疑，不阻止保存）：1.5px `--warning` 边 + 下方黄软底小条「格式可能不对，仍可保存」
- 密钥 textarea：默认掩码（`-webkit-text-security: disc` / 实现层可用逐行掩码渲染），右上角「显示 / 隐藏」，下方 muted「共 n 个密钥」

## 14. 国际化（i18n）

**语言**：`zh-CN`（简体中文，默认文案源）与 `en-US`。

**选择与记忆**

- 顶栏右侧（角色切换左侧）放分段胶囊 **「中 | EN」**；登录页同一位置（右上）也有。样式同角色切换：`--input-fill` 底，选中项白底 + `shadow-sm`，按钮最小宽 34px
- 优先级（最终口径）：① 用户手动选择 → ② 浏览器语言 `en*`（服务端看 `Accept-Language`，客户端看 `navigator.language`）→ 英文 → ③ 其他一律中文
- 用户手动点选后写入 cookie `shq-lang`（服务端渲染需要），并同步到 `localStorage['shq-lang']`（`zh` / `en`），以后始终优先；切换即时生效，不刷新页面；同时更新 `<html lang>`（`zh-CN` / `en-US`）与 `document.title`
- 服务端以 cookie 为准决定 `<html lang>`；没有 cookie 时按 `Accept-Language` 判断
