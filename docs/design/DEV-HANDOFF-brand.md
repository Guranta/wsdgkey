## 5. 登录页 bot 脸动画

- 尺寸 **96px**，水平居中在卡片标题上方，是登录页视觉焦点；下方一行「万事大吉」18px/700（次级色），再往下是标题「登录」。
- 实现：纯 CSS + 少量 JS（线框里约 60 行，`#loginFace` 和 `LF` 对象），**不引入任何依赖**。
- SVG 分层：`.lf-body`（身体 + 高光）›`.lf-look`（视线位移）›`.lf-open`（竖椭圆眼）/ `.lf-shut`（两条短横线）/ `.lf-happy`（∩∩）。用容器 class 切换状态：`blink` / `pw` / `happy` / `shake` / `hop`。

| 状态 | 触发 | 表现 | 时序 |
|------|------|------|------|
| 待机 | 默认 | 身体上下浮动约 2px | 4s ease-in-out 循环 |
| 视线跟随 | `pointermove`（仅待机） | 眼睛朝鼠标方向偏移，最大约 5px（viewBox 3.4 单位） | transition 180ms ease-out |
| 随机眨眼 | 定时器 | 眼睛 `scaleY(0.08)` 再恢复 | 每 3–6s 随机一次，闭眼 140ms |
| 看输入框 | 用户名 `focus` | 眼睛向下约 4.5px，不跟随鼠标 | 180ms |
| 闭眼 | 密码 `focus` | 眼睛换成两条短横线（不偷看），不眨眼 | 淡入淡出 120ms |
| 恢复 | 两个输入框都 `blur` | 回到待机 | — |
| 失败 | 提交失败（必填缺失 / 账号密码错误） | 左右摇头一次（±7px、±4°，递减） | 500ms，一次 |
| 成功 | 登录成功 | 眼睛变 ∩∩，压扁 → 上跳 12px → 回弹 | 跳 450ms，∩∩ 保持约 750ms 后跳转 |

注意：成功后点击按钮会让密码框失焦，失焦逻辑里要跳过 `happy` 状态，否则 ∩∩ 会被立刻重置。

## 6. 减少动态效果（prefers-reduced-motion: reduce）

- 关闭：浮动、眨眼（定时器不启动）、视线跟随（位移归零）、摇头、跳跃、所有 transition。
- **保留状态切换**：密码聚焦仍显示闭眼横线，成功仍显示 ∩∩（这是反馈信息，不是装饰）；成功后约 400ms 跳转。
- 用 `matchMedia('(prefers-reduced-motion: reduce)')` 并监听 `change`，系统设置变化时立即生效。
- 侧栏 / SVG 文件里的眨眼同样在 reduce 下关闭。
